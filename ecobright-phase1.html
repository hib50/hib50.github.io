EcoBright Motion-Sensing LED Validation Platform

A controlled mechatronics test platform developed at Toronto Metropolitan University’s ELIXIR Laboratory to validate occupancy-sensing LED behaviour, quantify energy savings, and evaluate PIR and microwave sensing under repeatable commercial occupancy scenarios.

PROJECT AT A GLANCE

From a commercial validation question to a repeatable physical test system.

The project examined whether occupancy-based LED control could reliably reduce lighting energy use while maintaining the intended sensing, dimming, standby and shut-off behaviour. Instead of relying on people to repeatedly walk through the sensing field, the research team developed an automated physical stimulus system capable of reproducing controlled motion events.

Testing covered five representative commercial environments — school, fitness centre, warehouse, shopping centre and parking garage — with the parking configuration evaluated using both PIR and microwave sensing.

ENGINEERING PROBLEM

How do you test occupancy sensing without introducing inconsistent human movement?

A major challenge was repeatability. Human participants would introduce uncontrolled changes in speed, path, body position and timing. To isolate the sensing system itself, the test bench required a repeatable physical target that could trigger the sensor on demand across long-duration tests.

The solution was a servo-driven actuator carrying a heated anodized-aluminum target. The heated plate provided a stable long-wave infrared source for PIR testing, while the moving aluminum target also served as a repeatable physical reflector during microwave-sensor evaluation.

SOFTWARE & DATA ACQUISITION

Turning physical sensor behaviour into analyzable time-series data.

ESP32 Test Automation

The embedded test program generated scenario-specific actuator behaviour and tracked fixture state during long-duration runs.

  • Servo motion generated from probabilistic occupancy profiles
  • Sensor activation and LED dimming-state acquisition
  • Dedicated 1-second hardware timer for continuous reporting
  • Servo position and active motion interval included in the telemetry stream

PC Logging & Analysis

The test computer added absolute timestamps and stored the incoming serial stream as CSV data for numerical analysis.

  • Python serial acquisition and timestamping
  • CSV logs backed up after each test cycle
  • MATLAB used for numerical processing and final energy analysis
  • Dynamic integration performed across approximately 90,000 rows per test

TEST METHODOLOGY

Five commercial occupancy profiles, one repeatable hardware platform.

Each profile changed the probability, timing and duration of actuator movement to represent a different real-world traffic pattern. Fitness and shopping scenarios used an 8/8/8 decompression model to represent high-activity, reduced-activity and overnight-off periods, while the remaining profiles used the raw compressed test data as a conservative baseline.

School

Low movement probability during class periods, followed by very high movement during simulated class changes.

Fitness Centre

Frequent activity checks with a high probability of movement to represent a busy gym environment.

Warehouse

High-activity worst-case model representing semi-continuous employee and equipment movement.

Shopping Centre

High-frequency traffic model designed to represent continuous pedestrian activity.

Parking Garage

Low-probability movement profile tested with both PIR and microwave configurations.

Controlled Variables

Actuator geometry, sensor placement and test-bench layout were held constant so sensor configuration remained the primary variable.

RESULTS

Substantial savings across every tested occupancy scenario.

Across the scenario models, estimated energy savings ranged from 35.24% in the high-activity warehouse case to 62.12% in the microwave-sensed parking case. The percentage savings remained consistent when the validated dimming behaviour was scaled across the evaluated fixture variants.

ENGINEERING CHALLENGES

Problems that had to be solved before the data meant anything.

Repeatable Occupancy Simulation

Human movement is inconsistent. A servo-driven physical target allowed the same movement logic to be reproduced over extended test periods.

PIR-Compatible Stimulus

Visible motion alone was not sufficient for realistic PIR activation. The target required a controlled thermal signature representative of a warm moving object.

Long-Duration Logging

Multi-hour tests required stable 1 Hz acquisition, absolute timestamps and reliable file handling without accumulating timing drift.

Converting Voltage Into Energy

Fixture dimming voltage was normalized against a calibrated reference and numerically integrated with true fixture wattage to estimate energy consumption.
