RASPBERRY PI / COMPUTER VISION / ROBOTICS

Control a robot with your hand.

I built a camera-driven robotic turret that interprets hand position and gestures using OpenCV and MediaPipe, then translates them into physical servo movement through a Raspberry Pi and Arduino control architecture.

Python · OpenCV · MediaPipe · Raspberry Pi · Arduino · UART · GPIO · PWM

Raspberry Pi workshop — hardware assembly and system integration.

THE IDEA

The camera doesn't just see a hand. It decides what the hand is asking the machine to do.

HUMAN → MACHINE

Three gestures. Three different actions.

01

One finger

Horizontal hand position becomes the target for the turret's X-axis movement.

02

Two fingers

Vertical hand position controls the Y-axis while the gesture remains active.

03

Closed fist

Holding a fist activates the timed Z-axis trigger sequence.

WHAT THE COMPUTER SEES

21 hand landmarks become control data.

MediaPipe tracks the joints and fingertips in the camera image. The Python program uses the landmark geometry to count raised fingers, calculate palm position, choose a control mode and generate servo targets.

WHY TWO COMPUTERS?

One handles intelligence. The other handles motion.

BRAIN

Raspberry Pi

Handles the computationally heavier software stack and decides what action the robot should take.

  • Linux environment
  • Python control program
  • OpenCV camera interface
  • MediaPipe hand tracking
  • Gesture interpretation
  • GPIO laser control
MUSCLE

Arduino

Receives the requested positions and provides the dedicated PWM outputs needed by the mechanical system.

  • X servo — pin 3
  • Y servo — pin 5
  • Z servo — pin 6
  • Angle limiting
  • Servo actuation
  • 115200-baud communication

HARDWARE CONNECTIONS

The electrical path behind the movement.

Pi TX → Arduino RX
Pi GND → Common Ground
Arduino D3 → X Servo
Arduino D5 → Y Servo
Arduino D6 → Z Servo
Pi GPIO 17 → Laser Signal

FROM PROJECT → WORKSHOP

Building it was only half the project.

I later used the system as the centerpiece of a hands-on Raspberry Pi workshop through the Mechatronics Course Union.

Instead of only demonstrating the finished robot, the workshop walked students through the entire stack: computing architecture, GPIO, UART, Arduino control, servo wiring, computer vision and calibration.

WHAT THIS PROJECT BROUGHT TOGETHER

Computer vision. Embedded control. Electronics. Mechanics. And teaching others how they connect.

The most valuable part of the project was not any one component. It was integrating a camera, Linux computer, vision pipeline, communication link, microcontroller and physical mechanism into one working system — then turning that system into something other students could build and understand.
