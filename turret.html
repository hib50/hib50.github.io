ROBOTICS • COMPUTER VISION • EMBEDDED CONTROL

Hand-Gesture Controlled Robotic Turret

A Raspberry Pi and Arduino robotic platform that uses OpenCV and MediaPipe hand landmarks to convert gestures and hand position into multi-servo motion and trigger control.

Raspberry Pi Python OpenCV MediaPipe Arduino UART / USB Serial Servo Control

SYSTEM OVERVIEW

Vision on the Pi, actuation on the Arduino

The Raspberry Pi processes the camera stream, detects a single hand using MediaPipe and maps palm position and finger-state information into X, Y and Z servo commands.

Commands are sent to the Arduino over serial, while the Raspberry Pi directly controls the laser GPIO.

GESTURE LOGIC

Natural hand input mapped to different control modes

One Finger

Confirmed one-finger detection enables X-axis control using filtered palm X position.

Two Fingers

Confirmed two-finger detection enables Y-axis control using filtered palm Y position.

Closed Fist

A held fist starts a timed trigger sequence that drives the Z-axis firing servo forward, then returns it.

No Hand

The laser is turned off and the trigger servo is returned to its back position.

CONTROL DETAILS

Filtering, limits and command rate

The Python program applies exponential filtering to X and Y hand coordinates before converting them to servo angles. The Arduino then clamps received angles to configured mechanical limits before issuing servo commands.

30 Hz

Configured command-send target in the Raspberry Pi control loop.

3 Servos

X, Y and Z channels for multi-axis motion and trigger actuation.

115200

Serial communication baud rate between Raspberry Pi and Arduino.

SOFTWARE PIPELINE

High-level control flow

Camera frame ↓ Mirror + RGB conversion ↓ MediaPipe hand landmarks ↓ Finger counting + palm position ↓ Mode selection (X / Y / trigger) ↓ Filtered coordinate-to-angle mapping ↓ "x,y,z" serial command ↓ Arduino angle clamp + servo.write()

ENGINEERING CHALLENGES

What the system had to solve

Noisy Hand Coordinates

Raw vision coordinates fluctuate frame-to-frame, so filtering was needed before servo mapping.

Gesture Confirmation

One- and two-finger states are confirmed across multiple frames to reduce accidental mode switching.

Mechanical Limits

Servo ranges are clamped in firmware to avoid commanding unsafe positions.

Distributed Control

The project splits high-level vision processing and low-level servo control across two computing platforms.
